# IA 462 — GitHub Open-Source Docker Project

**Eastern Michigan University | Fall 2026 | Instructor: Ryan Weber, MSIA**

This assignment requires each student to identify their own open-source GitHub project, build it using Docker, and document the complete process in a recorded video. The purpose is to demonstrate practical knowledge of open-source software, Docker containerization, systems administration, and security while following the same standards used in the other IA 462 labs, midterm, and final assignments.

## Project Objective
Students will:
- find a public open-source project on GitHub
- verify the project is suitable for local build and execution
- build the project using Docker
- troubleshoot any issues encountered
- document every step in a video submission
- explain the project’s purpose, setup, and security implications

## Required Deliverables
- a selected open-source GitHub project
- a Docker build process for that project
- written or recorded evidence of the build and troubleshooting steps
- a video explaining the process and outcomes
- a brief reflection tied to systems administration and security

## Assignment Requirements
This project must follow the same expectations as the other IA 462 assignments:
- hands-on execution
- clear technical documentation
- evidence of problem-solving
- professional communication
- practical understanding of security and administration
