# Rubric: GitHub Open-Source Docker Project

## Total: 200 Points

### 1. Project Selection and Relevance (20 points)
- Appropriate open-source GitHub project selected
- Project is active, documented, and usable
- Project connects to security, systems administration, Linux, networking, or infrastructure

### 2. Docker Build Process (40 points)
- Student demonstrates Docker build steps
- Dockerfile or Compose configuration is used correctly
- Build process is explained clearly
- Project is built successfully or issues are thoughtfully documented and resolved

### 3. Troubleshooting and Problem Solving (40 points)
- Student identifies issues encountered during the setup/build process
- Student explains how problems were diagnosed
- Student demonstrates effective troubleshooting and corrective action

### 4. Documentation Quality (40 points)
- Commands, outcomes, and issues are documented
- Evidence of the process is included
- Student presents work in a clear and understandable format

### 5. Video Quality and Presentation (30 points)
- Video is organized and understandable
- Student explains steps clearly
- Screen recording demonstrates the actual process
- Final outcome is presented professionally

### 6. Security and Administration Reflection (30 points)
- Student connects project work to operating systems security or administration
- Student identifies technical or security considerations
- Student provides a meaningful learning reflection

## Standards
This assignment follows the same expectations as the other IA 462 labs, midterm, and final work:
- professionalism
- technical accuracy
- evidence of hands-on work
- clear communication
- practical troubleshooting and reflection
