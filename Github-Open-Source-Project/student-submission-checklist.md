# Student Submission Checklist

Before submitting, confirm all of the following:

- [ ] I selected an open-source GitHub project
- [ ] I reviewed the project documentation
- [ ] I cloned the repository locally
- [ ] I used Docker to build or run the project
- [ ] I documented the commands used
- [ ] I recorded any errors or issues encountered
- [ ] I explained the troubleshooting process
- [ ] I completed a final build or runtime verification
- [ ] I recorded a video showing the process
- [ ] I included a short reflection on security and administration
- [ ] My submission is professional and technically accurate
